# DESIGN.md Library

Ready-to-use DESIGN.md files (the [Google Stitch DESIGN.md format](https://stitch.withgoogle.com/docs/design-md/overview/)) from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md). Each file in `designs/` holds YAML-frontmatter design tokens (colors, type scale, radii, spacing) followed by prose rules for layout, components, and do/don't guidance.

## How to use

1. Pick the design(s) matching the request from the index below. If the user named no brand, suggest 2–3 that fit the product and let them choose.
2. Read the full `designs/<name>.md` before writing any UI code. Don't work from the one-line summary.
3. Apply its tokens and rules: map the frontmatter colors/typography/spacing to the project's styling system (CSS variables, Tailwind theme, etc.) and follow its component and layout guidance.
4. If the user wants the style adopted project-wide, copy the file to `DESIGN.md` at the project root (adjusting brand-specific names, logos, and proprietary fonts) so later work stays consistent.

These specs are *inspired by* the named sites. Don't copy logos, trademarks, or proprietary assets. Substitute licensed or open fonts when a spec names a custom typeface.
